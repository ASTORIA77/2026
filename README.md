# 2026 年度纪事 · 网页

一个以手机为主的单页静态网页，用来回看 2026 年发生的事，在 2027 年新年时展示。只供浏览，没有编辑、备忘、导出功能。

直接用浏览器打开 `index.html` 即可，不需要服务器、不需要联网，也没有构建步骤。

---

## 一、文件结构

```
2026大事记/
├── index.html   页面本体：HTML + 内联 CSS + 内联 JS，全部在这一个文件里
├── data.js      内容文件：记事、祝福语、诗词、背景音乐
├── fonts/       本地字体（开源，附许可证）
├── images/      记事配图（现在只有两张示例 SVG）
├── music/       背景音乐（现在是空的）
└── README.md    本文件
```

## 二、页面现在有什么（从上到下）

1. **抬头**
   - 左上一个小胶囊「2026 · 年度纪事」。
   - 大号「2026」，其中「26」为蓝色。
   - 右侧两行右对齐：「回望来路 / 启航新程」，两行合起来的高度与「2026」字高一致（字号按 `--yr` 换算）。
   - 一句说明：「转动下面的年轮，一天一天看这一年发生了什么。」
2. **年轮（表盘）**
   - 365 天一圈，外圈是日刻度，内圈是十二个月的名字，顶部有一个固定的蓝色指针。
   - 中间只显示日期：「10月 · OCT」、大号的日数字、「星期四」。不显示事件标题，也不显示「有没有记录」。
   - 有记事的日子，在外圈显示一根加长的**蓝色刻度**。没有其他颜色的标记（没有节日红点、没有金色高光刻度、没有图例）。
   - 操作：拖动旋转（带惯性）；松手时 3 天内有记事会自动吸附过去；点刻度跳到那一天；有记事时点中间会滚动到下方记事卡片。
3. **滚动日历条**
   - 横向滚动的日期格，每格显示星期 + 日数字，选中日为蓝色方块。
   - 不显示「几月」。周末与节日（如中秋）在星期一行显示为红字。有记事的日子下面有蓝色小圆点。
   - 日历条与年轮双向同步。
4. **上一则 / 下一则** 按钮，中间显示「第 X / N 件」，在有记事的日子之间跳转。
5. **记事卡片**
   - 电脑端（宽度 ≥ 1000px）左右两栏：左栏年轮 + 日历条 + 上一则/下一则，右栏为记事卡片；右栏卡片底边与「上一则 / 下一则」底边持平，内容超出时卡片内部滚动。
   - 头部：大号日数字 + 「10月15日 · 星期四」 + 「2026 年第 288 天」。
   - 正文：标签、标题、图片、正文。所有事件内容只在这里显示。
   - 没有记事的日子：只显示「附近的纪事」，列出最近的几件，点击跳转。不写「这天没有记录」之类的话。
6. **页脚**
   - 「2026」+「新岁快乐 · 来日方长」。
   - 下方一个蓝色胶囊按钮「✦ 点击收获祝福」。
7. **祝福浮层**（点击「点击收获祝福」按钮后）
   - 全屏半透明磨砂背景 + 亮黄色细线烟花。
   - 中间依次浮现：「2026 → 2027」小胶囊、大字「新岁快乐」、1 句古诗词（两行，左对齐、整体居中，下带出处）、2 句祝福语、「轻点任意处关闭」。
   - 点任意处关闭，10 秒后自动关闭。
8. **吸顶迷你条**：年轮滚出屏幕后，顶部出现一条小栏。
   - 中间显示当前日期；有记事时显示第一件的标题，没有记事时只显示星期。
   - 左右两个箭头可跳到上一则 / 下一则；点中间会滚回年轮。
9. **背景音乐按钮**：只有当 `data.js` 里的音乐文件能播放时才出现；第一次触摸页面后开始播放。

## 三、改内容只需要动 `data.js`

### 记事 `window.EVENTS`

```js
{
  date:   '2026-03-12',             // 必须是 2026 年
  title:  '标题',
  tag:    '生活',                    // 卡片上的小标签，任意文字
  text:   '正文，可以换行。\n第二段。', // 可省略
  images: ['images/0312-1.jpg']      // 可省略，图片放 images/，建议最多 4 张
}
```

- 同一天可以写多条，顺序不限，页面自动按日期排列。
- 现在里面有 3 条「示例：」开头的占位记事（1 月 1 日、2 月 17 日、10 月 15 日），正式内容填好后需要删除。

### 送祝福 `window.POEMS` / `window.WISHES`

- `POEMS`：`{ t: '上句，下句', s: '作者《篇名》' }`，现有 14 句。页面按第一个逗号把诗句分成两行。
- `WISHES`：字符串数组，现有 16 句。
- 每次打开随机抽 1 句诗 + 2 句祝福。

### 背景音乐 `window.MUSIC`

- `src` 填 `music/` 下的文件名，`title` / `artist` 是按钮上显示的歌名与歌手。不要音乐就把 `src` 留空 `''`。
- 目前 `music/` 是空的，所以页面上暂时不显示音乐按钮。

## 四、视觉与技术约定（改页面时请保持）

- **整体风格**：现代蓝白，浅色背景，克制有节日感，不要显得像 AI 模板。只用浅色主题；正文用深色字；不用重阴影。
- **颜色变量**（`index.html` 顶部 `:root`）：
  - 背景 `--bg #F5F8FF`；文字 `--ink #0F1B33` / `--ink2 #4B5A75` / `--ink3 #8E9AB2`；分隔线 `--line #E2E9F6`
  - 主蓝 `--blue #2B6BFF`，深蓝 `--blue2 #1847C9`，浅蓝 `--blue-l #E6EEFF`；柔和蓝 `--blue-soft #6B95F2`（日历选中格、送祝福按钮用它，避免太夺目）
  - `--amber #FFA826`（烟花黄色系的基准）、`--coral #FF6B5B`（周末/节日红字、胶囊小圆点）
- **字体**（全部本地、开源）：
  - 中文：Noto Sans SC 400 / 700，CSS 里叫 `NSans`
  - 数字与英文：Outfit 300 / 500 / 700
- **字号**：已经按用户要求放大过多次（正文 19px，记事正文 20px）。不要再缩小。
- **烟花**：只用亮黄色系（`#FFA826` 到 `#FFD166`），线条形花丝，等角度、等速度地炸开成正圆，一共 3 朵（中、左、右依次）。不要改回多色、随机的样式。系统开启「减少动态效果」时不放烟花，只显示文字。
- **年轮实现**：SVG，`viewBox` 400，中心 `C=200`，`N=365`。当前选中日由旋转角计算：`sel = mod(round(-rot / STEP), N)`。
- **日历条**：格子宽度在运行时用 `measureCW()` 实测，不要写死。只有用户手动滚动日历条时（`userStrip` 标记）才反过来驱动年轮，避免两者互相触发。
- 所有代码都在 `index.html` 里，没有外部依赖、没有 CDN。

## 五、检查方法（Windows）

- 用 Edge 无头模式截图检查手机宽度效果：
  - 新建一个临时 HTML，里面放宽 375px 的 `<iframe>` 指向 `index.html`。
  - 运行 `msedge --headless --disable-gpu --user-data-dir=<每次新的临时目录> --allow-file-access-from-files --virtual-time-budget=<毫秒> --screenshot=<输出.png> --window-size=<宽,高> <临时html>`。
  - 有时第一次运行不出图，换一个新的 `--user-data-dir` 再跑一次即可。
- 想截到烟花：在 iframe 的 `onload` 里把 `requestAnimationFrame` 替换成 `setTimeout(16)`，再自动点击 `#wishBtn`。
- 检查完要删掉临时 HTML 和截图，`index.html` 里不要留测试用的代码。
